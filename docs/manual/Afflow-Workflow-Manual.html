Start here

Open Afflow and know what changed

Afflow keeps Terax's terminal, editor, file explorer, Git tools, and built-in AI surfaces. The additions turn that baseline into a persistent production workspace for affiliate content.

How to open it

  1. Open the Windows Start menu and search for Afflow.
  2. Installed application: C:\Users\Admin\AppData\Local\Afflow\afflow.exe
  3. Installer for another Windows PC: C:\Users\Admin\Afflow\src-tauri\target\release\bundle\nsis\Afflow_0.1.0_x64-setup.exe
Your current app is the installed Windows build.
It is already open and restoring local Afflow state.

Added over baseline Terax

WorkstationsSeparate files, tabs, layouts, tools, and browser choices by niche or project.
ScaffoldingCreates a predictable production folder tree and three role prompts.
Agent presetsLaunches four repeatable workflows through Claude, Codex, Gemini, OpenCode, or a custom CLI.
Browser toolsOpens saved sites in a normal Chrome or Edge window with Afflow-managed profiles.
Daily recoveryRestores saved workstation state and warns before losing dirty files or active work.
Windows packagingProvides an installable desktop application instead of requiring VS Code to run it.
Not implemented yet: cross-device cloud sync. Windows and macOS support is being prepared, but copying workstation files and UI state between your PC and MacBook belongs to the later Afflow Cloud phase.

Step 1

Create one workstation per niche or campaign

1

Create a clean root folder

Use a location such as Documents\Afflow Workspaces\Fit Check. Avoid using your whole home folder as the long-term workstation root.

2

Click the plus in Workstations

The plus creates and scaffolds a workstation. The folder icon opens an existing workstation.

3

Choose the folder

Afflow adds the standard folder tree and a minimal workstation.json. Existing prompt files are preserved and never overwritten.

4

Switch by clicking its row

Each row retains its own active files, terminal definitions, saved websites, profile mode, agent choices, and layout.

Recommended workstation split
Use separate workstations for Fit Check, Realistic AI Avatar, Health and Wellness, or any distinct brand, client, or campaign.

The Workstations rail. Use the plus to create, the folder to open, and a row to switch.

scripts/ images/ audio/ videos/ outputs/ workstation.json

Step 2

Launch a workstation agent

Click the tab plus, then select Agents.

Choose a role and a detected command-line agent, then launch it in the workstation root.

PresetUse it forExpected result
General AgentResearch, file organization, planning, and one-off work.Work completed inside the active workstation.
Script GeneratorShort-form affiliate scripts from verified product facts and audience notes.Hook, scenes, on-screen text, voice-over, CTA, and claims to verify.
Script ReviewerRisk review before production, especially health and wellness content.Risk level, line findings, required revisions, and a safer version.
Image-to-Video Prompt GeneratorTurn a source image and approved script into a tool-specific motion prompt.Main prompt, negative prompt, motion notes, continuity risks, and conservative alternate.
Side-by-side agents: press Ctrl+D or Ctrl+Shift+D, focus the new pane, choose a preset, then select Focused pane. For a new role, select New preset, enter its name, and paste the complete prompt.md content.
Two different agent surfaces exist. New Tab > Agents is the added workstation workflow launcher. Settings > Agents is Terax's global inline AI persona configuration.

Step 3

Use the browser profile that matches the job

Browser tools launch external websites. Afflow does not embed a browser and does not inspect page contents.

1

Open Browser tools

Click the browser icon beside Search and Settings.

2

Select a profile mode

This workstation isolates website sessions for the current niche. Shared reuses one Afflow profile across workstations.

3

Add or open tools

Use the saved Google Flow, Kling, Grok, TikTok, Shopee, and Facebook launchers, add your own, or click Open all.

4

Sign in in the opened browser

The managed profile is separate from your normal Chrome or Edge profile. Sign in once for that Afflow profile, subject to each website's session policy.

Use isolated mode by default.
It prevents two niche workstations from intentionally sharing login state. Use Shared only when cross-workstation reuse is the desired behavior.
Profile reset is destructive. Close the related browser first. Afflow refuses reset while the profile is active or its state is uncertain, and requires confirmation. It never resets your normal personal browser profile.

Configuration

Choose Chrome or Edge

Open the gear icon, then select Browser. This Windows machine currently detects both Chrome and Edge.

Normal setup

Select Chrome or Edge as the preferred browser. Afflow uses the detected executable and opens a normal external browser window.

Executable override

Use Choose .exe only when auto-detection misses a valid installation. Afflow validates the selected browser executable again before launch.

macOS direction: the native backend includes Chrome and Edge candidate detection and macOS profile lock probing. A physical Apple Silicon MacBook test and packaging pass are still required before the Mac build should be treated as accepted.

Recommended routine

Product-to-video workflow

1

Collect verified inputs

Put product facts in products, source material in references, and research notes in research. Keep claims tied to a source.

2

Generate the script

Launch Script Generator. Specify platform, niche, audience, duration, language, tone, and the exact source files to use. Save the result under scripts.

3

Review before production

Launch Script Reviewer against the saved script. Resolve unsupported claims and save the approved revision.

4

Prepare media

Place source images in images and audio in audio. Launch Image-to-Video Prompt Generator with target tool, duration, and aspect ratio.

5

Open production websites

Use Browser tools in This workstation mode. Open Flow, Kling, or Grok and upload the prepared media manually.

6

Bring results back

Download completed media to videos. Keep publish-ready exports and final documents in outputs.

7

Do the final platform check

Use TikTok, Shopee, or Facebook launchers for manual review and publishing. Afflow does not auto-post or bypass platform controls.

8

Save and close cleanly

Save edited files before closing. Afflow checks for dirty editors and active terminal work, persists the workstation state, and restores it on the next start.

Suggested naming convention

scripts/2026-08-25-product-angle-v01.md
videos/2026-08-25-product-angle-9x16-v01.mp4
outputs/2026-08-25-product-angle-approved/
Only saved files persist and will eventually sync. Unsaved editor buffers, terminal output, running processes, browser cookies, and CLI login state are device-local by design.

State and safety

What Afflow restores today

StateWindows todayAcross PC and Mac later
Saved workstation filesLocal Kept in your selected folder.Planned End-to-end encrypted file sync.
Workstation name, order, tools, layout, saved tabsRestored Local persistence and crash recovery.Planned Portable declarative state.
Terminal sessions and running processesRestored cold as definitions, not as live processes.Never migrated live between devices.
Browser profile and sign-inLocal Afflow-managed directory.Never synchronized. Sign in independently on each device.
CLI credentials and secretsStored by the CLI or OS credential store.Never synchronized by Afflow.
Crash recovery: Afflow writes durable workspace state and a clean-close marker. After an unclean shutdown, it offers recovery rather than silently discarding the last saved state.

Security boundaries

  • Every native file operation is constrained to an authorized canonical workstation root.
  • Browser launches use fixed arguments, not a shell, and never accept caller-supplied browser flags.
  • workstation.json contains identity and creation metadata only. It contains no cookies, tokens, process handles, or passwords.
  • Afflow never reads, exports, or synchronizes browser cookies or local storage.
  • Browser profile reset fails closed when activity cannot be proven idle.

Quick reference

First manual test checklist

  • Create a dedicated empty folder and add it as a new workstation.
  • Confirm the standard folders and three prompt files were created.
  • Switch away and back; confirm the workstation retains its state.
  • Open New Tab > Agents and launch Script Generator with Claude.
  • Save a sample script under scripts, then open it in Afflow.
  • Launch Script Reviewer and save a revised script.
  • Open Browser tools in This workstation mode.
  • Open one AI media site, sign in, close the browser, and launch it again.
  • Create a second workstation and verify its isolated profile is not signed in.
  • Switch both workstations to Shared mode and verify the shared profile is reused.
  • Upload and download one representative media file through the external browser.
  • Close Afflow with saved work, reopen it, and confirm workstation, tabs, layout, tools, and profile selection restore.

Troubleshooting

Agent unavailableInstall or authenticate the CLI, ensure its executable is on PATH, then reopen the Agent presets panel.
Prompt missingCheck the matching file under agents. Re-running scaffold is safe and preserves existing files.
Browser not detectedOpen Settings > Browser, refresh detection, or choose the exact Chrome or Edge executable.
Profile reset refusedClose every window using that Afflow profile and retry. Unknown activity is intentionally treated as unsafe.
Workstation folder movedUse the workstation relocation action to reconnect the saved workstation to its new root.
MacBook continuationUntil Afflow Cloud exists, move saved workstation files manually. Browser and CLI authentication must remain separate.
Current acceptance status: automated Windows checks and packaging are complete. Signed-in profile persistence, isolation, representative upload/download, sustained real workflow use, and physical MacBook acceptance remain manual validation items.
